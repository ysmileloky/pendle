📉 数据指标说明

APY（年化收益率）

  • 固定 APY - 购买 PT 代币锁定的收益率，到期保证获得
  • 浮动 APY - 底层资产的原生收益率，会随市场波动
  • Long Yield APY - 做多收益的策略 APY，适合看好未来收益增长的用户

其他关键指标

  • TVL (Total Value Locked) - 市场中锁定的总资金量
  • 24h 交易量 - 过去 24 小时的交易总额
  • 流动性 - 可以立即用于交易的资金池深度
  • 到期日 - 市场的结束时间，PT 代币兑付日期

💡 使用场景

场景 1: 寻找高收益市场

  1. 切换到表格视图
  2. 点击"固定 APY"列标题排序
  3. 查看顶部的高 APY 市场
  4. 点击市场查看历史趋势
  5. 确认 APY 稳定性后做出决策

场景 2: 评估市场安全性

  1. 查看市场的 TVL 和流动性
  2. TVL 越高 = 市场越成熟
  3. 流动性/TVL 比例 > 50% = 高健康度
  4. 检查到期日，避免即将到期的市场

场景 3: 对比不同链的机会

  1. 查看卡片右上角的链标识
  2. 对比同类资产在不同链上的 APY
  3. 考虑 gas 费和桥接成本
  4. 选择性价比最高的链
