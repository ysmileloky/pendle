📍 方式一：网络地址访问（推荐）

由于你是在远程服务器上运行项目，请使用以下网络地址：

http://21.0.0.74:3000
操作步骤：
1. 点击上面的蓝色链接
2. 或复制地址到浏览器地址栏
3. 按回车键访问

📖 查看项目文档

http://21.0.0.74:3000/docs.html

❓ 如果网络地址无法访问

可能的原因：
  • 你的 Mac 和服务器不在同一个网络
  • 服务器防火墙阻止了访问
  • 需要使用 VPN 或端口转发

🌐 方式二：部署到在线平台

如果上述方法都不行，可以将项目部署到 Vercel（免费），获得一个公开的网址：

部署到 Vercel：
1. 访问 vercel.com
2. 使用 GitHub 登录
3. 导入你的 pendle 项目
4. 点击 Deploy
5. 几分钟后获得一个 https://your-app.vercel.app 地址

💡 本地开发选项

如果你想在Mac本地运行项目：

步骤：
1. 将项目下载到你的 Mac
2. 打开终端（Terminal）
3. 进入项目目录：cd ~/Downloads/pendle
4. 安装依赖：npm install
5. 启动项目：npm run dev
6. 访问：http://localhost:3000
